# EX-02-01 — De quem veio esse detalhe?

Exercício de **A Era dos Agentes** — Parte II, capítulo 4, *A página em branco já não está sozinha*.

> As perguntas de observação e o conceito que este exercício demonstra estão no livro. Aqui fica só o que você precisa para executar.

## O que você vai ver acontecer

Uma ferramenta de conversa preencher, sozinha e sem avisar, informações que você nunca deu — e depois admitir que não as tinha.

## O que você precisa ter

Qualquer ferramenta de conversa que você já use. Nada para instalar. Dez minutos.

## Passos

1. Abra a ferramenta de conversa que você já usa.
2. Pegue o primeiro pedido no repositório e cole na conversa.
3. Leia a resposta inteira e marque cada informação específica que aparecer: nome, endereço, dia, horário, atividades, nomes de pessoas.
4. Conte quantas dessas informações vieram de você.
5. Cole o segundo pedido, que proíbe a invenção e manda declarar o que falta.
6. Ponha as duas respostas lado a lado.

## O pedido

Está em [`pedido.txt`](pedido.txt), pronto para copiar. Também há uma [página com botão de copiar](https://jjdsnt.github.io/books_resources/era/pt-BR/EX-02-01/).

### Primeiro pedido

```
Crie um anúncio curto para uma biblioteca comunitária que abrirá no próximo mês. Tom acolhedor.
```

### Segundo pedido

```
Reescreva sem inventar nome, endereço, data, horário ou atividades. Onde faltar informação, deixe o espaço marcado e me diga o que você precisaria saber.
```
