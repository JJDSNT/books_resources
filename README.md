## Como isto funciona · How this works

Cada exercício do livro tem um identificador estável (`EX-04-02`) que é **o
mesmo em todos os idiomas**. No livro impresso, um QR code leva à página do
exercício, com o pedido e um botão de copiar — você não precisa digitar nada.

*Each exercise has a stable id (`EX-04-02`), identical across languages. In the
printed book a QR code opens the exercise page, with the prompt and a copy
button — no typing needed.*

- Página do exercício · exercise page: `…/era/pt/EX-04-02/`
- Arquivos no repositório · files in the repo: [`era/pt-BR/`](era/pt-BR/)

## O que está aqui e o que está no livro

Este repositório carrega o **operacional**: o pedido, os passos, os requisitos,
como desfazer. O **entendimento** está no livro: por que o pedido é daquele
jeito, o que observar enquanto acontece, e o que o exercício demonstra.

Quem tiver só este repositório consegue executar os exercícios. Não é a mesma
coisa que aprender com eles.

## Gerado, não editado à mão

O conteúdo dos exercícios é **gerado a partir do manuscrito**. Um pedido
impresso no livro e outro entregue pelo QR seria o pior defeito possível deste
mecanismo, e a única forma de impedir isso é haver um lado só. Ver
[`AGENTS.md`](AGENTS.md).
